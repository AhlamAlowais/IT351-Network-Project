Physical Network Topology Setup
In this step I created the initial physical topology for the *SAMS* network using Cisco Packet Tracer

Added Devices:
1 Router (Router 2911)
2 Switches (Switch 2960)
6 End Devices (PCs: PC0 to PC5)

Connections:
Connected all PCs to their respective Switches using Copper Straight Through cables.
Connected Switch0 and Switch1 to Router0 using GigabitEthernet cables.
